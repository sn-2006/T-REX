# T-REX Landing Page

A responsive editorial-style landing page for T-REX — Crypto Compliance Infrastructure.

## Sections

1. Get Started / Hero
2. Problem Statement
3. Solution & Approach
4. Market Research
5. About Us
6. Navigation + Footer

## Design

- Dark charcoal + off-white + muted green
- Editorial typography inspired by the supplied visual reference
- Transaction network visualization built with inline SVG
- Responsive navigation
- Scroll-based active navigation
- Smooth scrolling
- No external image assets required

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

This is a standalone Vite + React landing page and can be merged into the existing T-REX frontend later.
