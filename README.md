# T-REX

## Crypto TDS Compliance, Automated & Verified

T-REX is a crypto tax compliance platform that helps users analyze and verify TDS obligations on Virtual Digital Asset (VDA) transactions in India.

### What T-REX Does

T-REX brings crypto transaction data from multiple exchanges such as CoinDCX and Binance into one platform. It:

- Imports and normalizes exchange transaction data
- Classifies transactions such as buys, sells, and transfers
- Reconciles transactions across multiple exchanges
- Identifies potential TDS gaps and discrepancies
- Generates AI-powered compliance insights
- Creates a compliance report
- Generates a SHA-256 fingerprint of the report
- Anchors the fingerprint on the Polygon blockchain for verification
